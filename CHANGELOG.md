# Changelog

## 1.0.0 — 2026-10-15

First release of Enhanced Timer: local and synchronized stopwatch/countdown timers, a Minecraft-style HUD with drag-and-drop positioning, native controls, four languages, four mod loaders and the separate Bukkit server plugin.

Includes the validated fixes for the 26.3 keybinding conflict, fast drag gestures, live language changes, custom payload handling and Folia scheduling. Full installation details, supported versions and test limitations are in [release/1.0.0.md](release/1.0.0.md).

The 0.2.0 development test reports are retained as historical evidence. Their version numbers and hashes are unchanged.

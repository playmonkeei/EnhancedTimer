# Enhanced Timer 1.0.0

A simple Minecraft-style stopwatch and countdown with a freely positioned HUD, optional server synchronization, and controls that work in Hardcore without cheats.

- Minecraft Java 26.1, 26.1.1, 26.1.2, 26.2 and 26.3; Java 25.
- Universal mod JAR per Minecraft family: Fabric, Quilt, Forge and NeoForge, on clients and dedicated mod servers.
- Separate Bukkit plugin for Spigot, Paper, Purpur and Folia.
- Start, pause, stop, reset, undo, splits, countdown warnings and a large expiration message.
- Native configuration screens, optional Mod Menu integration, and client commands. Default menu key: **B**.
- Drag-and-drop HUD editor, anchors, scaling, 16 Minecraft colors, rainbow and custom colors.
- German, English, French and Spanish; game-language selection with English fallback.
- Personal, global and team timers, permissions, saved profiles and optional challenge rules.

## Choose the right download

| Minecraft / server | File |
| --- | --- |
| 26.1, 26.1.1, 26.1.2 mod | `enhancedtimer-26.1-1.0.0.jar` → `mods/` |
| 26.2 mod | `enhancedtimer-26.2-1.0.0.jar` → `mods/` |
| 26.3 mod | `enhancedtimer-26.3-1.0.0.jar` → `mods/` |
| Bukkit server plugin | `enhancedtimer-server-1.0.0.jar` → `plugins/` |

The ZIP contains all downloads and documentation. Install only the appropriate JAR, and do not install the mod and plugin together on the same server. The client mod works on ordinary servers for local timers; shared timers require Enhanced Timer on the server. Fabric API is not required by Enhanced Timer. Mod Menu is optional; install its own dependencies when using it.

## Validation and scope

Development validation includes 60 automated test executions, a historical 50-scenario loader/server baseline, and targeted native GUI, Hardcore and two-player Paper/Folia tests under the former working name BetterTimer. After renaming to Enhanced Timer, fresh runtime checks cover Fabric on 26.1/26.2/26.3 and Quilt/Forge/NeoForge on 26.3 against Spigot. Historical reports retain their original names and hashes; current validation and scope are documented separately in `docs/RELEASE_1.0.0.json`.

Not every modpack, operating system, inventory interaction or challenge event has been manually tested. See `docs/TESTING.md` and `docs/MANUAL_TESTS.md`. No Bedrock, proxy installation, 26.4 or later compatibility is claimed. The embedded Java API is not a separately versioned stable integration API.

Please report issues with the Minecraft, Enhanced Timer and loader/server versions, reproduction steps, and a relevant log.
